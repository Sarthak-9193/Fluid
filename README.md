# Sarthak Jain — Portfolio

A monochrome editorial portfolio for **Sarthak Jain**, a B.Tech Computer Science and Engineering student at Symbiosis, Pune.

Built with plain HTML, Tailwind (CDN), WebGL (OGL) and scroll-driven animations — no build step.

## Sections

- **Home** — hero with intro
- **About** — scroll-expand media card
- **Education** — horizontal scroll timeline (school → B.Tech)
- **Projects** — WebGL carousel: [Canteen](https://sarthak-9193.github.io/canteen-name/) and [Strength Protocol](https://sarthak-9193.github.io/strength-protocol-/)
- **Skills** — Programming, Vibe Coding, Learning Web, Problem Solving
- **Contact** — form that opens your email app, plus GitHub link

## Run locally

```bash
npm start        # serves on http://localhost:8080
```

(or any static server: `python3 -m http.server 8080`)

## Customize

- Text and links: `index.html`
- Projects (title, description, link, image): `DEFAULT_ITEMS` in `flex-carousel.js`
- Project images: `Project Images/` — replace `Canteen.png` and `Strength Protocol.png` with real screenshots
- Hero portrait: replace `assets/hero_portrait.png` with your own photo (transparent PNG works best)
